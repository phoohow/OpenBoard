# 数据模型

本文定义持久化的三层结构（文件 / 白板 / 快照）、元素的判别联合与各 `kind` 专属字段、引用关系，以及读取外部数据时的归一化策略。类型源码在 `src/model/types.ts` 与 `src/domain/document.ts`。

## 三层结构

```ts
interface BoardsFile {          // localStorage 'OpenBoard:v1' 的整体内容
  version: 1
  activeId: string
  boards: BoardDoc[]
  settings: AppSettings
}

interface BoardDoc {            // 一块白板
  id: string
  name: string
  elements: BoardElement[]
  view: View
  updatedAt: number
  comments?: BoardComment[]
  route?: RouteStop[]
  snapshots?: Snapshot[]
}

interface Snapshot {            // 历史版本
  id: string
  name: string
  createdAt: number
  auto: boolean
  elements: BoardElement[]
  view: View
}

interface View { x: number; y: number; zoom: number }
```

约束：

- `version` 固定为字面量 `1`，用于未来迁移；当前读取时忽略该值，直接按结构归一化。
- `activeId` 必须命中 `boards` 中的某项，否则回落到第一块白板。
- `comments` / `route` / `snapshots` 是可选字段，读取时缺失即视为空数组；写入时未改动就不产生该键。
- `settings` 在文件级而非白板级：切换白板不改变背景、吸附等设置。

## AppSettings 与 View

| 类型 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `AppSettings` | `background` | `'dots'` | `dots / grid / lines / plain`，非法值回落 `dots` |
| | `snap` | `true` | 吸附，仅 `false` 才关闭 |
| | `guides` | `true` | 智能参考线，仅 `false` 才关闭 |
| | `autoColor` | `true` | 新建元素自动轮换颜色 |
| `View` | `x` / `y` | `40` / `30` | 平移量，非有限数回落默认 |
| | `zoom` | `1`（`clampZoom`） | 夹在 `0.1 ~ 3` 之间 |

`clampZoom` 同时服务于视图与导入数据，是缩放的唯一收敛点；上下限就是同文件的 `MIN_ZOOM` / `MAX_ZOOM`（`app/config.ts` 只转出给界面，背景轮转用的 `BACKGROUND_MODES` 也在这里）。

## BoardElement

单一接口 + `kind` 判别，全部字段可选值用 `?` 表达。通用字段：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | `string` | 元素唯一 id，`uid()` 生成 8 位 36 进制串 |
| `kind` | `ElementKind` | `sticky / text / shape / connector / draw / image / frame / mindnode / table / card` |
| `x` / `y` / `w` / `h` | `number` | 画布坐标与尺寸（未旋转时的外接盒） |
| `text` | `string?` | 正文；表格用 `cells`，图片无文字 |
| `fill` / `stroke` / `textColor` | `string` | 颜色，允许 `'transparent'` |
| `strokeWidth` / `fontSize` | `number` | 描边宽度与字号 |
| `bold` / `align` / `opacity` | `boolean` / `'left' \| 'center' \| 'right'` / `number` | 文字样式与整体透明度 |
| `rotation` | `number?` | 顺时针角度，归一化到 -180~180 |
| `locked` / `visible` | `boolean?` | 锁定后不参与命中与变换；`visible === false` 不渲染 |
| `dash` | `boolean?` | 虚线与虚线边框 |
| `groupId` | `string?` | 群组标识，同组整体选中与联动 |

各 `kind` 的专属字段：

| kind | 专属字段 | 说明 |
| --- | --- | --- |
| `sticky` | `autoSize`、`votes` | `autoSize` 默认 `true`，文字变长时自动撑高；`votes` 为投票票数 |
| `text` | 无 | 宽度固定时按 `wrapText` 折行 |
| `shape` | `shape` | `ShapeKind` 52 选 1，默认 `round` |
| `connector` | `from`、`to`、`points`、`connectorStyle`、`arrowStart`、`arrowEnd`、`dash` | `from` / `to` 指向被连接元素 id；`points` 是画笔与旧数据的手绘点；`connectorStyle` 为 `straight / elbow / curve` |
| `draw` | `points` | 扁平坐标数组 `[x1,y1,x2,y2,...]`，画笔与橡皮产物 |
| `image` | `src` | data URL，整张图存在文档里 |
| `frame` | 无专属字段 | 容器按包围盒收纳子元素，不写 `parent` |
| `mindnode` | `parent`、`rootId`、`collapsed`、`mindLayout` | 父指针建树；`rootId` 标识所属导图；`mindLayout` 只在根节点上有意义 |
| `table` | `rows`、`cols`、`cells`、`header` | `cells` 行优先扁平数组，长度 `rows * cols`；`header` 强调首行 |
| `card` | `status`、`owner`、`due`、`desc`、`done` | 卡片是任务式元素，`status` 默认 `'进行中'` |

`baseElement(kind, x, y)` 给出所有默认值，是新建元素的唯一工厂：

| kind | 默认尺寸 | 默认文案 | 默认填充 |
| --- | --- | --- | --- |
| `sticky` | 200×160 | 双击输入想法… | `#FFF1A8` |
| `text` | 240×56 | 添加文本 | `transparent` |
| `shape` | 200×160 | 流程节点 | `#E9E0FF` |
| `frame` | 720×480 | 未命名容器 | `transparent` |
| `table` | 480×180 | 表格 | `#FFFFFF` |
| `card` | 260×152 | 任务卡片 | `#FFFFFF` |
| `mindnode` | 200×56 | 新节点 | `#FFFFFF` |
| `image` / `draw` / `connector` | 200×160 | 空 | `#E9E0FF` |

图形另有一层默认尺寸：`SHAPE_GROUPS` 中带 `size` 的条目按条目尺寸，其余用 `shapeDefaultSize`（180×88）。

跨文件共用的三个默认色也定在 `model/constants.ts`：`DEFAULT_FILL`（`#E9E0FF`，形状默认填充）、`DEFAULT_STROKE`（`#B9A8EA`，形状 / 表格描边与导图连线回落色）、`DEFAULT_INK`（`#292630`，默认字色）。`createElement` 只写与工厂不同的部分（便签配色、形状与表格尺寸、画笔粗细等）。

## 引用关系

元素之间没有对象引用，全部用 id 字符串关联。删除、复制、移动时都要按这张表联动处理：

| 引用 | 持有方 | 语义 | 联动规则 |
| --- | --- | --- | --- |
| `from` / `to` | `connector` | 连接线两端 | 删除端点时默认连带删除该连接线（`elements/remove` 的 `dropConnectors`） |
| `parent` / `rootId` | `mindnode` | 导图父子与所属树 | 删除节点时默认连带整棵子树（`cascadeMind`） |
| `groupId` | 任意元素 | 群组成员 | 成组/解组只改这个字段，不解散父子关系 |
| `elementId` | `BoardComment` | 评论挂载点 | 元素删除后评论保留但不再有角标 |
| `targetId` | `RouteStop` | 路线站点优先聚焦元素 | 元素不存在时回落到 `x` / `y` / `zoom` |
| `frame` | 无字段 | 容器靠几何包含关系（`frameChildren` / `isInsideFrame`）而非 id | 移动容器时按包含关系带走子元素 |

`board/duplicate` 是唯一需要重映射引用的地方：它先为所有元素生成新 id，再用 `Map` 重写 `from` / `to` / `parent` / `rootId` / `groupId`，否则副本会指向原白板的元素。

## 归一化与兼容

`parseFile(raw)` 是外部数据的唯一入口（localStorage 读取与 JSON 导入都走它）：

1. `boards` 不是数组 → 视为空；每个条目必须有数组型 `elements`，否则丢弃。
2. `id` / `name` 缺失时补 `uid()` 与「未命名白板」。
3. 元素逐个过 `isValidElement`，非法条目静默丢弃，不阻塞整份文件。
4. `view` 走 `normalizeView`，`settings` 走 `normalizeSettings`；`comments` 要求 `id` 与 `text` 均为字符串，`route` 要求 `id` 为字符串。
5. 白板全部非法时返回 `defaultFile()`——首块白板为 `launchBoard()` 的示例内容，视口 `{ x: 40, y: 24, zoom: 0.8 }`。
6. `activeId` 不在 `boards` 中时取第一块白板的 id。

兼容策略是「宽进严出」：读取时尽量修补，写入时永远输出结构完整的 `BoardsFile`。因此新增可选字段不需要写迁移代码，老数据缺字段时由默认值或渲染层兜底。

导图还有一层运行时归一化：`normalizeMindmaps(elements)` 会在每次影响导图的命令后、以及切换白板时重算节点尺寸与位置。它返回原数组引用表示「无需变更」，调用方据此跳过 dispatch。
