# 扩展指南

本文按「想加什么」组织，每类改动给出完整链路（改哪些文件、按什么顺序）与验证方式。所有路径都是仓库相对路径，改完都要过 [快速上手](快速上手.md) 里的三道门禁。

## 一、新增元素类型

元素类型由 `kind` 判别，新增一个 `kind` 等于同时在模型、渲染、交互三处登记。

| 步骤 | 文件 | 改什么 |
| --- | --- | --- |
| 1 | `src/model/types.ts` | `ElementKind` 加成员；需要新字段就加到 `BoardElement` 上 |
| 2 | `src/model/factories.ts` | `baseElement` 补该 kind 的默认尺寸、文案、填充 |
| 3 | `src/model/constants.ts` | 若需要默认尺寸常量或颜色预设，加在这里 |
| 4 | `src/canvas/renderers/render.tsx` | `renderElement` 的 `switch` 加分支 |
| 5 | `src/canvas/renderers/<x>.tsx` | 新建渲染器，内部用 `wrapNode(el, inner)` 包裹 |
| 6 | `src/geometry/hitTest.ts` 或 `box.ts` | 若命中/包围盒有特殊性，补分支 |
| 7 | `src/app/actions/elements.ts` | 新增 `addX(...)` action，`dispatch({ type: 'elements/add' })` |
| 8 | `src/app/interaction/pointer.ts` | 创建分支：点一下生成、拖拽生成或走手柄 |
| 9 | `src/app/interaction/keyboard.ts` | 若需要独立工具键，加进 `TOOL_KEYS` |
| 10 | `src/ui/layout/ToolRail.tsx` | 工具条加按钮（工具总数会变，记得同步文档） |
| 11 | `src/ui/layout/PropertyPanel.tsx` | 加该类型的属性区（可选） |
| 12 | `src/canvas/TextEditorOverlay.tsx` / `EditingOverlay.tsx` | 文本可编辑则接入编辑浮层 |
| 13 | `src/ui/dialogs/DataDialogs.tsx` 统计 | 若统计需要分类，补字段 |

验证：新元素能创建、能拖动缩放、能撤销、能导出（SVG/PNG 与画布一致）、选区导出不漏。导出无需改代码——`buildExportSVG` 克隆的是画布真实节点，只要渲染器带 `data-id` 就自动生效。

## 二、新增图形

图形是形状元素的参数，不新增 `kind`。

| 步骤 | 文件 | 改什么 |
| --- | --- | --- |
| 1 | `src/model/types.ts` | `ShapeKind` 加成员，并按语义归到 `ShapeCategory` |
| 2 | `src/model/constants.ts` | `SHAPE_GROUPS` 对应分组加 `{ id, label, size? }`；特殊尺寸进 `SHAPE_SIZES` |
| 3 | `src/geometry/shapes.ts` | 在 `shapePath`、`shapePolygon` 或 `shapeInnerLines` 中补分支；椭圆类加到 `isElliptical` |

渲染器不需要改：`ShapeElement` 按 `isElliptical → shapePath → shapePolygon → rect` 取第一个可用结果。

验证：图形库面板能搜到、能插入、改宽高后轮廓不变形；`npm test` 不回归（图形几何目前无单测，建议手测 + 目视导出一张 PNG）。

## 三、新增模板

| 步骤 | 文件 | 改什么 |
| --- | --- | --- |
| 1 | `src/features/templates/library.ts` | `TEMPLATES` 加一项 `TemplateSpec`：`id`、`name`、`desc`、`accent`、`category`、`build()` |
| 2 | 同上 | 若开新分类，补 `TemplateCategory` 与 `TEMPLATE_CATEGORIES` |
| 3 | `src/domain/fixtures.ts` | 复用里面的构造助手快速拼内容 |

`build()` 返回一个 `Board`，模板库里真实的元素数量由 `spec.build().elements.length` 现算，不需要手写计数。

验证：模板库展示新卡片与真实缩略图、搜索能命中、收藏能吃、套用后替换当前白板内容且可撤销（`applyTemplate` 会弹二次确认）。

## 四、新增导出格式

| 步骤 | 文件 | 改什么 |
| --- | --- | --- |
| 1 | `src/features/export/<x>.ts` | 新建导出函数，入参沿用 `(content, defs, bounds, name, ...)` |
| 2 | `src/features/export/svg.ts` 或同类新文件 | 直接导出新函数，由 `app/actions/io.ts` 按文件导入 |
| 3 | `src/app/actions/io.ts` | 新增 `exportX()`：先 `commitEdit()`，再取 `exportTargets`、算 `bounds`、`setBusy` |
| 4 | `src/ui/dialogs/ExportDialogs.tsx` | 加按钮，并在 `DialogHost` 的 props 里补该 action 的类型声明 |
| 5 | 文档 | 更新 [持久化与导出](持久化与导出.md) 的格式表与用户文档「数据与导出」 |

硬约束：新格式必须复用 `buildExportSVG` 或它的克隆结果，不要另画一套，否则会与画布漂移。

验证：三种范围（全部 / 选区 / 视口）× 透明与不透明两种背景都能产出正确文件；空选区给出错误提示而不是空文件。

## 五、新增命令

完整五步在 [状态与命令](状态与命令.md) 的「新增一条命令的五步」。这里补充清单：

1. `src/domain/commands/<域>.ts`：命令类型 + reducer。
2. `src/domain/commands/command.ts`：导出类型与 reducer。
3. `src/domain/reduce.ts`：注册进 `fileReducers` 或 `boardReducers`。
4. `src/app/actions/<域>.ts`：包一层 action。
5. `test/domain/commands/<域>.test.ts`：至少三条用例。
6. 文档：本页不需要改，但 [状态与命令](状态与命令.md) 的命令表与 [模块地图](模块地图.md) 要补。

注意三点：reducer 未命中返回 `null`；内容未变返回原引用；只有确实不该进撤销栈才传 `history: false`。

## 六、新增面板或对话框

| 步骤 | 文件 | 改什么 |
| --- | --- | --- |
| 1 | `src/model/types.ts` | `DialogKind` 加成员 |
| 2 | `src/ui/dialogs/<X>Dialog.tsx` | 新建组件，用 `src/ui/common/Modal.tsx` 提供壳 |
| 3 | `src/ui/dialogs/DialogHost.tsx` | 加 `{dialog === 'x' && <XDialog …/>}` 分支，并补 props 类型 |
| 4 | `src/app/actions/ui.ts` | 如需新开关，加 `setX`；否则复用 `setDialog('x')` |
| 5 | 入口 | `TopBar.tsx` / `Sidebar.tsx` / `CanvasOverlay.tsx` 加触发按钮 |
| 6 | `src/styles/dialogs.css` 或 `panels.css` | 加样式类 |

面板（常驻、跟随选择变化）放 `src/ui/panels/`，由 `PropertyPanel` 或 `CanvasOverlay` 条件挂载；对话框（遮挡式）放 `src/ui/dialogs/`，统一由 `DialogHost` 路由。

验证：`Esc` 能关闭；打开时点击遮罩行为符合预期；面板在演示态下被隐藏（`ui.presenting` 判断）。

## 七、新增持久化数据

给白板或元素加字段时，优先加**可选字段**，这样老数据不需要迁移。

| 层级 | 步骤 |
| --- | --- |
| 元素字段 | `src/model/types.ts` 加可选字段 → `src/model/factories.ts` 给默认值 → 渲染/面板读取 |
| 白板字段 | `src/domain/document.ts` 的 `BoardDoc` 加字段 → `parseFile` 里归一化（缺失补默认）→ `createBoardDoc` 与 `board/duplicate` 的复制分支补上 |
| 文件字段 | `BoardsFile` 加字段 → `defaultFile()` 补默认 → `parseFile` 归一化 |
| 独立数据 | 若与白板无关（例如收藏），放 `src/features/storage/` 另起一个键，不要塞进 `OpenBoard:v1` |

需要写入时按「命令 → reducer → action」的老路走；持久化由 `installPersistence` 自动跟随 `state.file` 变化，不需要改保存逻辑。

兼容性三条：

- `parseFile` 必须容忍字段缺失与类型错误，非法值回落默认。
- `board/duplicate` 的复制分支要带新字段，否则副本丢数据。
- JSON 导出只含 `elements`，白板级新字段不会随导出走——如果需要，得同时改 `exportJSONFile` 与 `importJSON`。

验证：老数据（旧版本 localStorage）能正常加载；导出 JSON 再导入不丢字段；复制白板后新字段还在。
