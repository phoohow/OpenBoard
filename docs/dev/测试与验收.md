# 测试与验收

本文说明测试目录约定、当前覆盖范围、领域纯函数的测试写法，以及发布前必须满足的验收基线。三层门禁的分工是：`npm test` 管逻辑、`npm run check` 管结构、`npm run build` 管类型与产物。

## 测试配置

`vite.config.ts` 里同时配了构建与测试：

```ts
test: {
  include: ['test/**/*.test.ts'],
  environment: 'node',
}
```

- 只收集 `test/` 下以 `.test.ts` 结尾的文件，不进入 watch（脚本是 `vitest run`）。
- `environment: 'node'`：没有 DOM、没有 `localStorage`。这正是 `model / geometry / domain / features` 四层被禁止依赖 React 的原因——它们必须能在这个环境里直接跑。
- 别名 `@` 与源码一致，测试里用 `@/domain/...` 导入。
- 测试与源码分开放：`test/` 镜像 `src/` 的目录结构，`test/domain/commands/elements.test.ts` 对应 `src/domain/commands/elements.ts`。

## 领域纯函数测试写法

三条约定：

1. **用 fixtures 造数据**：`src/domain/fixtures.ts` 提供 `board(elements)` 与 `el(kind, patch)`，不要手写完整 `BoardElement`。
2. **只测 reducer，不测 action**：reducer 是纯函数，直接 `reduceX(board(elements), cmd)`；断言「未命中返回 `null`」与「内容未变返回原板引用」。
3. **命令字面量要带 `as const` 或用 `Parameters<typeof reduceX>[1]`**：命令是判别联合，字面量类型收窄靠这个。

示例骨架：

```ts
import { describe, expect, it } from 'vitest'
import { reduceElements } from '@/domain/commands/elements'
import { board, el } from '@/domain/fixtures'

const apply = (elements: BoardElement[], cmd: Parameters<typeof reduceElements>[1]) => {
  const next = reduceElements(board(elements), cmd)
  if (!next) throw new Error('命令未被处理')
  return next.elements
}

it('remove 连带删除导图子树与相关连接线', () => {
  // 造数据 → 施加命令 → 只断言结果数组
})
```

新增命令至少覆盖三种情形：正常生效、无事可做（返回 `null` 或原引用）、边界（空 id 列表、锁定元素、越界移动）。

## 三道门禁

| 命令 | 作用 | 失败意味着 |
| --- | --- | --- |
| `npm run check` | 依赖方向、纯层禁 React、旧符号残留 | 分层被破坏，或有人绕开 `dispatch` 写状态 |
| `npm test` | 55 条领域用例 | 命令语义回归 |
| `npm run build` | `tsc -b` 全量类型检查 + `vite build` | 类型错误或产物构建失败 |

`npm run check` 的判定细节见 [目录结构与分层](目录结构与分层.md)。

## 产品范围

明确做什么：

- 无限画布上的文本、便签、图形（52 种）、连接线、画笔、图片、容器、导图、表格、卡片。
- 选择与变换、群组、图层、六向对齐与分布、查找替换。
- 多白板、JSON 导入导出、PNG / SVG / PDF、Markdown 双向、画布统计。
- 三种演示模式（元素 / 幻灯片 / 路线）、激光笔、计时器、互动表情。
- 评论批注与便签投票（本地记录，非多人实时）。

明确不做：

- 多人实时协作、云端同步、账号体系。
- 服务端版本历史；历史版本只存在本地。
- 移动端适配与触摸手势优化（桌面端优先）。
- 除 Markdown 之外的文件格式导入（如 `.pptx`、`.drawio`）。

## 非功能基线

- 桌面端优先，建议最小宽度 1024px；窗口缩到更窄时布局允许压缩但不横向溢出。
- 首屏无需登录，所有依赖都能本地构建，不请求任何后端接口。
- 导出结果必须与画布视觉一致（同源 SVG）；异常路径不得清空已有数据。
- 所有破坏性操作（清空白板、删除白板、套用模板、导入 JSON、恢复版本）都要二次确认或可撤销。
- 界面文案全中文，按钮有 `title` 提示，主要操作都能用键盘完成。

## 验收清单

发布前逐条确认：

1. 新建、移动、缩放、旋转、编辑、删除各类元素均生效；锁定元素不被误改。
2. 移动被连接元素后，连接线端点自动贴边跟随；三种走线都能正常切换。
3. 撤销 / 重做能覆盖最近编辑；换板后撤销栈清空；拖拽只产生一条历史记录。
4. 刷新页面内容恢复；导入 JSON 能替换当前白板；导入后视口自动适配内容。
5. 模板套用、图形插入、素材插入、Markdown 导入都能落到当前白板且可撤销（Markdown 为追加）。
6. PNG（1x/2x/4x、透明背景、三种范围）、SVG、PDF/打印均可输出，且与画布一致。
7. 演示三种模式可进入退出，方向键与 `Enter` 步进，`Esc` 退出并收起激光笔与计时器。
8. 评论只能挂在元素上，解决态可切换；投票只在便签与卡片上生效。
9. `npm run check`、`npm test`、`npm run build` 三条全部通过。
