# OpenBoard 文档中心

OpenBoard 的文档按读者分成两部分：**用户文档**解决「怎么把白板用起来」，**开发者文档**解决「怎么改这份源码」。两部分互不混用，也不要求交叉阅读。

## 先选一条阅读路径

- 我只想画白板、做演示、导出文件：从 [用户文档 · 快速开始](user/快速开始.md) 进入。
- 我要改代码、加功能、跑测试：从 [开发者文档 · 快速上手](dev/快速上手.md) 进入。
- 我想先知道项目是什么：回到仓库根目录的 [README](../README.md)。

## 写文档的约定

- 全中文，标题最多三级，每篇开头有导语、结尾有「相关文档」。
- 用户文档不写源码路径、内部符号、包管理与构建命令；开发者文档必须给出仓库相对路径与真实符号。
- 数量与阈值类事实（图形种类、模板数量、缩放范围、快照保留条数等）以代码当前实现为准，改动功能时同步改文档。
- 相对链接只能指向仓库中真实存在的文件；新增文档要同时更新本页索引。
- 不使用 emoji。

## 功能改动时的文档同步清单

- 改了界面文案或交互：更新 `docs/user` 中对应篇目。
- 新增或修改命令：更新 [状态与命令](dev/状态与命令.md) 的命令表。
- 新增元素类型、图形、模板或导出格式：更新 [扩展指南](dev/扩展指南.md) 与 [模块地图](dev/模块地图.md)。
- 改了持久化参数或导出规则：更新 [持久化与导出](dev/持久化与导出.md)。
- 新增测试目录或验收口径：更新 [测试与验收](dev/测试与验收.md)。
