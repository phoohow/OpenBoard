# 快速开始

OpenBoard 是跑在浏览器里的本地优先白板：打开就能画，不用注册账号，内容留在你自己的浏览器里。这篇文档帮你在五分钟内做出第一块白板，并先把「数据存在哪里」这件事说清楚。

## 产品是什么

OpenBoard 提供一张无限大的画布，你可以在上面组合这些内容：

- 便签、文本、图形与连接线，用来记录想法和梳理流程。
- 画笔、图片、橡皮，用来自由标注与补充素材。
- 思维导图、表格、任务卡片与容器，用来组织结构化信息。
- 评论与便签投票，用来收集意见。

典型用途是头脑风暴、流程梳理、项目规划、复盘与轻量演示。

「本地优先」有两层含义：一是所有功能都在当前浏览器里完成，不依赖账号和网络；二是数据默认只保存在当前浏览器，需要分享或迁移时由你主动导出文件。

## 数据边界（建议先读）

- 白板内容保存在**当前浏览器的本地存储**里，不会上传到任何服务器。
- 换浏览器、换电脑、清理浏览器数据、使用无痕窗口，都可能看不到原来的白板。
- 想长期保存或发给别人，用顶栏「导出」保存一份 JSON 源文件；需要时用「文件 → 导入 JSON」还原。
- 顶栏会显示保存状态：`已保存到本机`、`保存中…`、`保存失败`。出现「保存失败」时请立即导出一份 JSON 备份，常见原因是浏览器存储空间不足或被浏览器设置禁止写入。

## 做出第一块白板

### 第 1 步：打开与认识默认白板

第一次打开会看到一张「产品发布计划」示例白板，里面已经放好便签、文本与连接线。你可以直接在它上面改，也可以新建一张空白白板。

### 第 2 步：新建自己的白板

两种方式：

- 顶栏「文件」菜单里的「新建白板」。
- 左侧「白板」标题右侧的加号按钮。

新建的白板叫「未命名白板」。改名的两种方式：

- 直接在顶栏中间的名称输入框里改。
- 在左侧白板列表双击该白板，输入新名称后按回车。

### 第 3 步：放下第一张便签

按 `N` 切到便签工具（或点左侧工具条的便签按钮），在画布上点一下，便签会立即创建并进入输入状态，输入完点画布空白处或按 `Esc` 结束编辑。

选中便签后，右侧属性面板可以调整颜色、尺寸预设，并开关「自动撑高」；标签页的「工具预设」里还能开启「彩虹换色」，让之后新建的便签自动轮换颜色。

### 第 4 步：移动、缩放与旋转

- 拖动元素即可移动；拖动时若靠近其他元素，会出现对齐参考线并自动吸附，按住 `Alt` 可跳过吸附。
- 选中单个元素后，拖动右下角的手柄缩放。
- 旋转在属性面板的「外观与位置」里：拖「旋转」滑杆，或使用逆时针、顺时针 90 度与「归零」按钮。画布上没有拖拽旋转手柄。

### 第 5 步：把两个元素连起来

按 `C` 切到连接线工具，从一个元素按住并拖到另一个元素，松开即生成连接线。选中连接线后，属性面板可切换直线、折线、曲线，开关起点与终点箭头，并填写线上的文字标注。

### 第 6 步：确认已经保存

改动停下后，顶栏保存状态会从「保存中…」变成「已保存到本机」。这时刷新页面，内容仍在。

### 第 7 步：演示或带走

- 想现场讲解：点顶栏「演示」，用方向键或 `Enter` 逐项切换，`Esc` 退出。
- 想留存或发给别人：点顶栏「导出」，选择 PNG、SVG、JSON、PDF 或 Markdown。

## 界面分区速览

| 区域 | 位置 | 主要用途 |
| --- | --- | --- |
| 顶栏 | 页面最上方 | 文件菜单、白板名称、保存状态、撤销重做、演示、路线图、分享、导出、属性面板开关 |
| 左侧栏 | 画布左侧 | 搜索与替换、白板列表、模板库、素材库、快捷插入、演示与投票入口、历史版本、画布统计、快捷键 |
| 工具条 | 画布左边缘 | 13 个创作工具切换 |
| 画布 | 中间 | 无限画布与所有元素，右下有缩放条、左下有小地图 |
| 属性面板 | 画布右侧 | 选中元素的属性、图层、对齐分布，以及当前工具的新建预设 |
