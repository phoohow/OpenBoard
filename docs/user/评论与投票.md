# 评论与投票

评论用来把意见钉在具体元素上，投票用来快速收敛选项。两者都在本机保存，不涉及多人实时同步。

## 评论批注

### 添加评论

1. 选中要批注的元素（或用评论工具点击它）。
2. 直接用评论工具时：按 `D` 切到评论工具，点击目标元素，工具会自动切回选择工具并选中该元素，同时属性面板出现评论输入框。
3. 在「评论批注」输入框里写下内容，点「添加评论」或按 `Enter` 提交（`Shift` + `Enter` 换行）。

没有选中元素时，输入框会提示「先选中一个元素再写评论」，按钮不可用。评论一定是挂在某个元素上的。

### 查看与处理

- 有未解决评论的元素右上角会出现一个橙色圆形标记，标记里是评论的第一个字，便于在画布上快速定位。
- 选中该元素后，属性面板的评论列表会显示它的全部评论，包含内容与时间。
- 每条评论有两个操作：勾选（标记已解决 / 重新打开）与删除。
- 已解决的评论不再在画布上显示标记。

### 评论的边界

- 评论按元素记录，元素被删除后它的评论也没有入口可查看。
- 评论不进入撤销栈，误删评论无法用 Ctrl/⌘ + Z 恢复。
- 评论不随 JSON 导出，也不会出现在导出的图片里。

## 便签投票

### 开启与投票

1. 左侧「演示与互动」区点「便签投票」，按钮变为「投票进行中」。
2. 在画布上点击便签或卡片，每点一次加一票，并提示「… +1 票」。
3. 点在非便签、非卡片的元素上会提示「请点击便签或卡片投票」。

投票模式下，有票数的元素右上角会显示紫色圆形票数标记。

### 查看结果

属性面板的投票区按票数从高到低列出前 8 名（元素文字截断显示）与票数，可以直接在讲解时当作排行展示。

### 清零与结束

- 点投票区的清零按钮会清空全部票数，并提示「票数已清零」。
- 再次点左侧「投票进行中」按钮可退出投票模式。

### 注意

- 票数保存在白板里，会随 JSON 导出。
- 投票不进入撤销栈，清零后无法撤销。
- 画布统计里的「便签投票」是当前白板全部票数之和。
- 演示状态下投票区与评论面板会隐藏，避免遮挡画面。
