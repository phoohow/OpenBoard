# 演示与分享

OpenBoard 的演示不导出幻灯片文件，而是直接在画布上逐项聚焦。这篇文档说明三种演示模式、演示工具条上的功能，以及怎么把白板交给别人。

## 开始演示

三种进入方式，效果一致：

- 顶栏「演示」按钮。
- 左侧「演示与互动」区的「开始演示」。
- 演示路线图弹层里的「按路线演示」。

顶栏与侧栏默认用「分页（容器）」模式；如果白板里一个容器都没有，会自动改成逐元素演示。演示开始时当前选区会被清空，属性面板隐藏，页面上只保留演示控制条与左上角的进度提示。

## 三种演示模式

演示控制条上可以随时切换，切换后会回到第一项。

| 模式 | 顺序 | 适用场景 |
| --- | --- | --- |
| 逐元素 | 全部元素从上到下、从左到右 | 边讲边展开，适合共创过程 |
| 分页（容器） | 按容器逐页；没有容器时退化为逐元素 | 已用容器分好页的正式讲解 |
| 路线图 | 按你设定的站点顺序 | 跨区域讲解，需要跳跃与补充细节 |

切换焦点时画布会自动缩放并居中到目标：容器会留出更大边距以显示整页，普通元素则放大到便于看清。

## 演示中的操作

| 操作 | 按键或按钮 |
| --- | --- |
| 下一项 | `→`、`↓`、`Enter`，或控制条右箭头 |
| 上一项 | `←`、`↑`，或控制条左箭头 |
| 激光笔 | `L`，或控制条「激光笔」 |
| 退出演示 | `Esc`，或控制条「退出」 |
| 平移画面 | 直接拖动 |

控制条还会显示 `当前 / 总数` 与当前项的标题（元素文字或容器名称）。

## 激光笔

打开激光笔后，鼠标在画布上移动会显示一个光点，方便远程讲解时指向内容。再按一次 `L` 或点按钮关闭。

## 计时器

- 预设 1 分钟、3 分钟、5 分钟、10 分钟，点一下即设定；默认是 5 分钟。
- 点时间按钮或「开始计时 / 暂停计时」控制运行与暂停。
- 计时归零后再点开始会从设定时长重新计时。

## 互动表情

控制条上有六个表情按钮：鼓掌、点赞、爱心、庆祝、火焰、笑脸。点击后表情会从画面中飘起，约两秒半后消失，适合线上会议时快速反馈。

## 演示路线图

顶栏「路线图」或控制条的「编辑路线」打开路线图弹层。

- **加入当前视角**：把此刻的画面位置与缩放记成一站。
- **加入容器**：从弹出列表里选一个容器，作为一站。
- 站点自动命名为「第 N 站 · 名称」。
- 每个站点可以「上移」「下移」「移除」，也可以「清空路线」。
- 点「按路线演示」按顺序逐站聚焦。

路线按白板保存，切换白板不会互相影响。

## 分享

顶栏「分享」打开分享弹层，当前版本是本地优先，没有云端链接与实时协作。两种交接方式：

1. **复制信息**：把白板名称与产品名复制到剪贴板，方便粘贴到聊天里说明。
2. **导出版本副本**：导出 JSON 文件，对方在 OpenBoard 里用「文件 → 导入 JSON」打开即可继续编辑。

如果只是想给对方看画面，用「导出 → PNG / SVG / PDF」更方便，对方不需要打开 OpenBoard。

## 演示前的小检查

- 想用分页模式：确认内容都放进了容器，且容器名称清晰。
- 想用路线模式：先把路线排好顺序，避免演示时手忙脚乱。
- 元素被锁定或隐藏时不会影响演示顺序，但隐藏元素在演示中也不可见。
- 评论与投票标记在演示中自动隐藏，画面更干净。
