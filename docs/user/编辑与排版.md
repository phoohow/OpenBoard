# 编辑与排版

画完元素之后的大部分工作，都是在「选中、摆好、分层、对齐」。这篇文档把编辑相关的操作集中说明。

## 选择

| 目标 | 操作 |
| --- | --- |
| 选中单个元素 | 用选择工具（V）单击 |
| 追加或取消选中 | 按住 Shift 单击 |
| 框选一片区域 | 在空白处按住拖动，框到即选中 |
| 全选 | Ctrl/⌘ + A（自动跳过已锁定元素） |
| 取消选择 | 点击空白处，或按 `Esc` |

命中规则上，内容元素优先于容器：点容器内部的内容会选中内容本身，只有点到容器空白处才选中容器。

## 移动与微调

- 拖动即可移动；多个元素同时选中时一起移动。
- 方向键移动 1 像素，`Shift` + 方向键移动 10 像素。
- 拖动时靠近其他元素会出现参考线并吸附；按住 `Alt` 可临时跳过吸附。
- 拖动容器会带走落在它范围内的元素；拖动导图节点会带走整棵子树；群组成员会一起移动。

## 缩放

- 选中单个元素后，拖动右下角手柄缩放。
- 也可以在属性面板「外观与位置」直接填宽、高，最小 20。
- 表格、卡片按整体缩放；文字会按元素宽度自动换行重排。

## 旋转

旋转只在属性面板里做：拖「旋转」滑杆（-180°–180°）、点逆时针或顺时针 90°，或点「归零」。旋转对连接线不生效。

## 复制、剪切、粘贴与再制

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 复制 | Ctrl/⌘ + C | 复制选中元素到剪贴板 |
| 剪切 | Ctrl/⌘ + X | 复制后删除原元素 |
| 粘贴 | Ctrl/⌘ + V | 粘贴到当前视野中心并选中 |
| 再制 | Ctrl/⌘ + D | 在原位置右下偏移 28 像素处复制一份 |

复制导图节点会带上整棵子树；两端都在选区内的连接线会随元素一起复制，并自动指向新的副本。

## 群组与解组

- 选中两个及以上元素，按 Ctrl/⌘ + G 成组，之后点击其中一个即可带动整组移动。
- 解组：再按一次 Ctrl/⌘ + G（选中整组时），或按 Ctrl/⌘ + Shift + G。
- 锁定元素不会被成组。

## 图层与显隐

每个元素在层级里都有顺序，后画的在上层。

- **置顶 / 置底**：属性面板「图层与操作」。
- **上移一层 / 下移一层**：右侧「图层」列表里每一项右侧的上下箭头。
- **锁定**：面板按钮或 Ctrl/⌘ + L，锁定后不能拖动、编辑与删除，删除时会提示先解锁。
- **隐藏**：图层列表里的眼睛图标，隐藏的元素不显示，也不参与导出。
- 容器不受层级影响，始终画在最底层。

## 样式

- 填充：12 色板（便签、文本、图形、容器、表格、卡片可用）。
- 描边：10 色墨色加「透明」，粗细 0–12，可开虚线。
- 文字：颜色、字号 10–64、加粗、左中右对齐。
- 不透明度：10%–100%。
- 修改会作用于所有选中元素，已锁定的元素会被跳过。

## 对齐与分布

- 选中两个及以上元素，属性面板出现六向对齐：左对齐、水平居中、右对齐、顶部对齐、垂直居中、底部对齐。
- 选中三个及以上才能使用水平分布与垂直分布，分布会把中间元素在两端之间等距排开。
- 排版时先对齐再分布，通常比手动拖更快。

## 查找与全局替换

左侧栏顶部提供两个输入框：

- **搜索白板内容**：按元素文字匹配，命中后自动选中并缩放到这些元素；没有命中会提示「没有找到包含…的内容」。
- **替换为…**：输入替换文本后回车或点「替换全部」，会把当前白板中所有匹配文字一次性替换，并提示替换了多少处。

搜索匹配的是元素的文字内容，包括便签、文本、图形文字、导图节点、卡片标题、连接线标注与容器名称；表格单元格内的文字与卡片描述不参与匹配。

## 编辑文字的细节

- 双击元素进入编辑，浮层会精确覆盖在元素上，所见即所得。
- 表格双击进入单元格编辑，`Tab` 下一格、`Enter` 下一行。
- 导图节点编辑时，`Enter` 提交并新建同级节点，`Tab` 提交并新建子节点。
- 按 `Esc` 或点击空白处提交编辑。
