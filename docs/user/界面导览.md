# 界面导览

这篇文档按屏幕区域说明界面上都有什么、点下去会发生什么。按钮名称与界面文案保持一致，方便你对照查找。

## 整体布局

页面分五块：顶栏在最上方，左侧是侧边栏，画布占据中间大片区域，画布左边缘贴着工具条、右下角是缩放条、左下角是小地图，右侧是属性面板（可收起）。

## 顶栏

从左到右依次是：

| 元素 | 说明 |
| --- | --- |
| 品牌区 | 显示 OB 标识与「OpenBoard · 本地优先的白板」 |
| 文件 | 打开下拉菜单，见下方说明 |
| 白板名称 | 直接输入即可改名，改动立即生效 |
| 保存状态 | `已保存到本机`、`保存中…`、`保存失败` 三种 |
| 撤销 / 重做 | 对应 Ctrl/⌘ + Z 与 Ctrl/⌘ + Shift + Z，无历史时按钮置灰 |
| 演示 | 用「分页（容器）」方式开始演示；白板里没有容器时自动改为逐元素演示 |
| 路线图 | 打开演示路线图弹层 |
| 分享 | 打开分享弹层，说明当前版本不支持云端实时协作 |
| 导出 | 打开导出弹层 |
| 面板开关 | 显示或隐藏右侧属性面板，演示时面板自动隐藏 |

「文件」菜单包含：新建白板、导入 JSON、创建副本、清空内容、删除白板。其中「清空内容」可以撤销；「删除白板」不可撤销，删除最后一个白板时会自动补一张空白白板。

## 左侧栏

自上而下分为六段：

1. **搜索与替换**：搜索框按元素文字匹配，命中后自动选中并缩放到这些元素；下方「替换为…」输入替换文本，回车或点「替换全部」执行全局替换。
2. **白板**：标题右侧加号用于新建；列表里每项显示名称与元素数量。单击切换白板，双击进入重命名；右侧「…」菜单提供重命名、创建副本、删除。
3. **模板**：打开模板库。
4. **素材**：打开素材库；下方快捷区可直接插入便签、文本、图形、图片、卡片。
5. **演示与互动**：开始演示、演示路线图、便签投票（开启后按钮显示「投票进行中」）。
6. **底部**：历史版本、画布统计、快捷键。

## 工具条（13 个工具）

工具条竖排贴在画布左边缘，悬停可看到名称与快捷键。

| 工具 | 快捷键 | 用途 |
| --- | --- | --- |
| 选择 | V | 选中、拖动、框选、缩放元素 |
| 抓手 | H | 平移画布 |
| 便签 | N | 在画布上点一下创建便签 |
| 文本 | T | 创建一段独立文本 |
| 图形 | S | 按当前选中的图形轮廓创建图形 |
| 连接线 | C | 从一个元素拖到另一个元素建立连线 |
| 画笔 | P | 手绘笔迹 |
| 橡皮 | E | 点击或涂抹删除元素 |
| 表格 | R | 插入表格 |
| 卡片 | K | 插入任务卡片 |
| 评论 | D | 点击元素并写评论 |
| 思维导图 | M | 创建导图中心主题 |
| 容器 | F | 拖拽划定一块区域作为容器 |

新建类工具（便签、文本、图形、卡片、表格、导图）用完后会自动切回选择工具，方便立刻继续调整。

## 画布浮层

- **小地图**（左下）：显示全部元素与当前视野框，点击小地图可把视图跳到该位置。
- **缩放条**（右下）：缩小、当前百分比（点击回到 100%）、放大、适配内容、吸附开关（磁铁图标）、背景样式按钮（点一次换一种：点阵、网格、横线、空白）。
- **演示提示**（左上）与**演示控制条**（底部）：只在演示时出现。

## 属性面板

面板头部显示「属性」或「已选中 N 个元素」。内容按条件出现：

- **填充**：12 色板，适用于便签、文本、图形、容器、表格、卡片等。
- **描边**：10 色墨色板加重叠色「透明」、粗细滑杆（0–12）、「虚线描边」开关。
- **图形形状**：选中对象全部是图形时出现，可切换 52 种轮廓并星标收藏。
- **连接线**：选中对象全部是连接线时出现，可切换直线、折线、曲线，开关起点箭头与终点箭头，并填写「连接线标注」。
- **文字**：便签、文本、图形、导图节点可用，含文字颜色、字号（10–64）、加粗与左中右对齐。
- **外观与位置**：透明度（10%–100%）、旋转滑杆（-180°–180°）、逆时针 90°、顺时针 90°、归零，以及 X、Y、宽、高数值输入。
- **图层与操作**：锁定、置顶、置底、复制、删除。
- **对齐与分布**：选中两个及以上元素时出现六向对齐；选中三个及以上才启用水平与垂直分布。
- **图层**：按层级列出全部元素，可点击选中、上移一层、下移一层、锁定、隐藏。
- **工具预设**：跟随当前工具，提供新建元素的默认样式，例如便签颜色、图形填充、笔型、卡片字段、表格行列与导图布局。

## 弹层与提示

| 弹层 | 打开方式 | 主要操作 |
| --- | --- | --- |
| 模板库 | 左侧「模板库」 | 分类筛选、搜索、收藏、套用 |
| 素材库 | 左侧「素材库」 | 表情贴纸、符号图标、评议印章，点击插入画布中央 |
| 导出白板 | 顶栏「导出」 | 选范围、倍数、背景，导出 PNG/SVG/JSON/PDF/Markdown |
| 分享 | 顶栏「分享」 | 复制白板信息、导出版本副本 |
| 快捷键 | 左侧栏底部 | 查看按键表 |
| 历史版本 | 左侧栏底部 | 保存当前版本、恢复、删除 |
| 画布统计 | 左侧栏底部 | 查看元素总数、评论、票数、锁定与隐藏数量、类型分布 |
| 演示路线图 | 顶栏「路线图」 | 添加站点、排序、清空、按路线演示 |
| 确认弹层 | 删除、清空、套用模板、导入等 | 二次确认，避免误操作 |

页面右上（浮动提示）会短暂显示操作结果，例如「已复制 3 个元素」「已导出 PNG」「本机保存失败，请导出 JSON 备份白板内容」。
