# 画布与视图

画布是无限大的：元素可以放在任意坐标，你看到的只是其中一个窗口。这篇文档说明怎么缩放、平移、切换背景，以及吸附与多白板怎么工作。

## 无限画布是什么意思

画布没有边界，元素坐标可正可负。常用的三个概念：

- **世界坐标**：元素真正所在的坐标，只在你新建元素或输入 X、Y 时才需要关心。
- **视图**：你当前看向哪里、放大了多少。每个白板单独记住自己的视图与缩放。
- **适配内容**：一键把所有元素装进视野。

## 缩放

缩放范围是 **10% – 300%**，超出会被限制在边界上。

| 操作 | 方式 |
| --- | --- |
| 以指针为中心缩放 | 鼠标滚轮 |
| 以画布中心缩放 | 缩放条上的加号、减号，或 Ctrl/⌘ + 加号 / 减号 |
| 回到 100% | 点击缩放条中间的百分比数字 |
| 适配全部内容 | 缩放条上的适配按钮，或按 Shift + 1 |
| 演示时聚焦某一项 | 演示中按方向键或 Enter |

适配内容会自动留出边距，且最多放大到 140%，避免内容很少时被放得过大。

## 平移

四种方式，效果相同：

- 选择抓手工具（H）后拖动。
- 任何时候按住 `Space` 临时切换为平移，松开恢复。
- 按住鼠标中键拖动。
- 演示模式下直接拖动画面。

## 小地图与跳转

左下角小地图画出全部元素的位置与当前视野框。点击小地图任意位置，视图会以该点为中心跳过去，适合在大白板上快速搬家。

## 背景样式

缩放条右侧的背景按钮每次点击按「点阵 → 网格 → 横线 → 空白」循环切换。背景只影响观感，不影响元素与导出结果；导出的背景由导出弹层里的「白色 / 透明」决定。

背景的间距会跟着缩放同步变化，所以放大时网格不会变形。

## 网格吸附、参考线与跳过吸附

- **网格吸附**：拖动元素时，位置会对齐到网格。
- **智能参考线**：拖动时如果与其他元素或容器边缘接近，会出现对齐线并自动吸附，方便对齐。
- **吸附开关**：缩放条上的磁铁按钮控制是否吸附，关闭后拖动完全自由。
- **临时跳过**：拖动时按住 `Alt`，本次拖动不吸附，松开后恢复。

## 多白板

一个 OpenBoard 里可以放多张白板，用来分主题（例如「需求梳理」「排期」「复盘」）。

- 切换：左侧「白板」列表单击。
- 新建：顶栏「文件 → 新建白板」，或左侧白板标题右侧的加号。
- 重命名：左侧列表双击，或改顶栏名称。
- 副本：左侧「…」菜单或顶栏「文件 → 创建副本」。
- 删除：左侧「…」菜单或顶栏「文件 → 删除白板」，删除不可撤销。

白板之间互相独立：元素、视图、评论、演示路线与历史版本都各自保存。

## 画什么也不会画丢

元素即使被拖到看不见的地方也不会消失，按 Shift + 1 适配内容就能找回；左侧搜索框输入文字也会自动选中并缩放到命中的元素。
