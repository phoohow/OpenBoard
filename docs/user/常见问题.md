# 常见问题

下面按「数据」「保存」「导入导出」「功能」「性能」归类，列出使用中最容易遇到的问题与处理办法。

## 我的白板存在哪里

保存在当前浏览器的本地存储中，不上传服务器，也不需要账号。所以清理浏览器数据、换浏览器、换电脑、无痕窗口都会看不到原来的白板。

## 换电脑或换浏览器怎么带走白板

两步：在旧环境用顶栏「导出 → JSON 源文件」保存文件；在新环境用「文件 → 导入 JSON」导入。注意导入会替换当前白板的内容，导入前会弹确认框。

收藏的图形与模板属于本机偏好，不随 JSON 一起导出。

## 清理浏览器缓存会丢数据吗

会。白板与浏览器数据存在一起，清理「网站数据 / Cookie 及网站数据」通常会把白板一并清掉。清理前请先导出 JSON 备份。

## 顶栏显示「保存失败」怎么办

说明当前改动没能写入本机存储。请立刻用「导出 → JSON 源文件」保存一份，然后检查：

- 浏览器是否禁止该站点保存数据（隐私设置、无痕模式）。
- 本机存储空间是否已满，可以删掉不用的白板或大图片。
- 是否同时在多个标签页打开了同一个白板，关掉多余标签页后重试。

## 新建的白板为什么叫「未命名白板」

新建时使用默认名称。改顶栏中间的名称框，或在左侧列表双击即可改名。名称为空时会提示「白板名称不能为空」。

## 图片插入后越来越卡

图片以数据形式保存在白板里，图片越多越大，保存、渲染与导出都越慢。建议插入前先压缩图片，或删掉不再使用的图片。

## 导入 JSON 失败

常见原因：

- 文件不是 OpenBoard 导出的 JSON，或内容被编辑器改坏。
- 文件里没有可用元素，会提示「文件中没有可用元素」。

可以先确认文件能正常打开、内容里包含元素列表，再重新导入。

## 导出图片时提示没有内容

- 白板为空：先添加元素。
- 范围选了「选中元素」但当前没有选区：先选中要导出的元素，或把范围改成「全部内容」。
- 元素被隐藏：隐藏元素不参与导出。

## 导出的 PDF 没有直接保存

「PDF / 打印」会打开系统打印窗口，需要在打印对话框里把目标改成「另存为 PDF」。如果窗口没打开，通常是浏览器拦截了弹出窗口，允许后重试。

## 搜索找不到内容

搜索只匹配元素的文字内容，表格单元格里的文字与卡片描述不参与匹配。可以先用其他元素承载关键词，或直接双击元素查看完整内容。

## 元素拖不动、删不掉

多半是被锁定了。查看属性面板「图层与操作」是否显示「已锁定」，或在图层列表里点开锁图标；也可以按 Ctrl/⌘ + L 解锁。

## 为什么没有拖拽旋转手柄

旋转目前只在属性面板「外观与位置」里做：滑杆、逆时针 / 顺时针 90°、归零。画布上只提供右下角缩放手柄。

## 评论能不能钉在画布空白处

当前只能在元素上批注：先选中元素（或用评论工具点击元素），再在评论面板里写内容。

## 支持多人实时协作吗

当前版本是本地优先的单机体验，不提供云端同步与实时协作。协作方式是通过 JSON 文件交接，或用导出图片 / PDF 共享结果。

## 套用模板后内容没了

套用模板会替换当前白板的全部内容（这是设计如此），但操作可以撤销：按 Ctrl/⌘ + Z 或点顶栏撤销按钮即可回到套用前。

## 恢复历史版本会不会把现在的改动冲掉

恢复会把白板还原到该版本，但恢复本身可以撤销。如果担心，先点「保存当前版本」留一个手动版本，再恢复其他版本。

## 白板数量有限制吗

界面没有硬性限制，可以按需要新建。实际能存多少取决于浏览器给该站点分配的存储空间。
