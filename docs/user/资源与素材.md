# 资源与素材

除了自己画，OpenBoard 还提供三类现成资源：图形库、模板库与素材库，并且支持把常用项收藏起来。

## 图形库

图形库出现在两个地方，数据是同一份：

- 属性面板「工具预设」：使用图形工具时出现，决定下一个图形的轮廓与填充。
- 属性面板「图形形状」：选中对象全部是图形时出现，用来替换轮廓。

分组与数量（共 52 种）：

| 分组 | 数量 | 典型图形 |
| --- | --- | --- |
| 基础形状 | 20 | 矩形、圆角矩形、圆形、椭圆、三角形、菱形、五边形、六边形、八边形、梯形、平行四边形、星形、右箭头、下箭头、十字、心形、横幅、对话气泡、云形、标签 |
| 流程图 | 10 | 开始 / 结束、判断、数据输入、文档、显示、手动输入、跨页引用、子流程、延迟、准备 |
| BPMN | 5 | 活动 / 任务、网关、数据存储、消息事件、批注 |
| UML | 4 | 类、包、组件、注释 |
| ER 图 | 3 | 实体、属性、联系 |
| 网络拓扑 | 7 | 服务器、数据库、路由器、交换机、防火墙、终端、移动设备 |
| 其他符号 | 3 | 人物、甘特条、树形 |

每个图形右侧的星标可以收藏；切到「收藏」标签就能只看到收藏过的图形。收藏为空时会提示如何收藏。

## 模板库

左侧「模板库」打开，共 **25 套模板**，分 6 个筛选标签：全部、空白、战略分析、研究与归因、共创会议、图表与流程，另外还有「收藏」。

| 分类 | 模板 |
| --- | --- |
| 空白 | 空白白板 |
| 战略分析 | SWOT 分析、商业模式画布、波特五力模型、波士顿矩阵、安索夫矩阵、GROW 教练模型、OKR 目标对齐 |
| 研究与归因 | 用户旅程地图、用户画像、5 Why 根因分析、鱼骨图、竞品对比矩阵、AARRR 增长模型 |
| 共创会议 | 头脑风暴、思维导图、卡片看板、迭代复盘、康奈尔笔记、时间管理四象限 |
| 图表与流程 | 产品发布计划、产品路线图、基础流程图、技术架构拓扑、组织结构图 |

使用要点：

- 顶部搜索框按模板名称与用途搜索，例如输入「复盘」「流程」。
- 卡片上除了名称与说明，还会显示元素数量；除空白模板外都有真实缩略预览。
- 右上角星标可收藏，之后在「收藏」标签里快速找到。
- **套用模板会替换当前白板的全部内容**，套用前会弹确认框；这个操作可以撤销，套用后白板名称会改成模板名称。

## 素材库

左侧「素材库」打开，共三组：

| 分组 | 数量 | 内容 |
| --- | --- | --- |
| 表情贴纸 | 12 | 开心、思考、很赞、鼓掌、喜欢、星星、灵感、加速、目标、风险、完成、疑问 |
| 符号图标 | 12 | 星标、心形、菱形、圆形、三角、箭头、勾选、叉号、旗帜、设置、时间、邮件 |
| 评议印章 | 6 | 通过、驳回、待确认、重点、待评审、已定稿 |

点击任意一项会插入到当前视野中央并选中：表情尺寸最大，符号次之，印章是带倾斜角度的文字块，适合给方案「盖章」。插入后可当作文本继续修改颜色、位置与大小。

## 收藏

- 可以收藏的对象有两类：图形轮廓与模板。
- 收藏保存在本机，关掉浏览器再打开仍然在。
- 收藏属于本机的个人偏好，不随白板 JSON 导出，也不会出现在别人导入的白板里。

## 素材与文件体积

素材与图片都是白板内容的一部分。插入大量图片后，本地保存与导出都会变慢，必要时可以删掉不用的图片，或把大图压缩后再插入。
