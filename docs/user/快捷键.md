# 快捷键

按键说明中的 `Ctrl` 在 macOS 上对应 `⌘`。全局快捷键在输入框、文本编辑、单元格编辑等输入状态下都不生效；`Esc` 例外，它用于退出编辑或关闭弹层。编辑框内的 `Tab` 与 `Enter` 由编辑框自己处理，见下方「思维导图」与「表格」两节。

## 工具

| 工具 | 按键 |
| --- | --- |
| 选择 | V |
| 抓手 | H |
| 便签 | N |
| 文本 | T |
| 图形 | S |
| 连接线 | C |
| 评论 | D |
| 容器 | F |
| 画笔 | P |
| 橡皮 | E |
| 思维导图 | M |
| 表格 | R |
| 卡片 | K |

## 编辑与文件

| 操作 | 按键 |
| --- | --- |
| 撤销 | Ctrl + Z |
| 重做 | Ctrl + Shift + Z 或 Ctrl + Y |
| 复制 | Ctrl + C |
| 剪切 | Ctrl + X |
| 粘贴 | Ctrl + V |
| 原位置再制（右下偏移） | Ctrl + D |
| 全选（跳过锁定元素） | Ctrl + A |
| 锁定 / 解锁所选 | Ctrl + L |
| 成组 | Ctrl + G |
| 解组 | Ctrl + Shift + G（或选中整组时再按 Ctrl + G） |
| 删除所选 | Delete 或 Backspace |
| 微调位置 | 方向键（1 像素） |
| 大步微调 | Shift + 方向键（10 像素） |
| 跳过吸附 | 拖动时按住 Alt |

## 思维导图

| 操作 | 按键 |
| --- | --- |
| 添加子节点 | Tab |
| 添加同级节点 | Enter |
| 重命名节点 | F2 |
| 编辑中提交并继续加子节点 | 编辑框内按 Tab |
| 编辑中提交并继续加同级节点 | 编辑框内按 Enter |

## 画布与视图

| 操作 | 按键 |
| --- | --- |
| 缩放 | 鼠标滚轮，或 Ctrl + 加号 / 减号 |
| 临时平移 | 按住 Space 拖动，或按住鼠标中键拖动 |
| 适配全部内容 | Shift + 1 |
| 退出编辑、关闭弹层、退出演示、清空选择 | Esc |

## 演示

| 操作 | 按键 |
| --- | --- |
| 下一项 | → 或 ↓ 或 Enter |
| 上一项 | ← 或 ↑ |
| 激光笔开关 | L |
| 退出演示 | Esc |

## 表格

| 操作 | 按键 |
| --- | --- |
| 进入单元格编辑 | 双击单元格 |
| 下一格 | 编辑中按 Tab |
| 下一行 | 编辑中按 Enter |
