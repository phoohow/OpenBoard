# 数据与导出

OpenBoard 的数据都留在本机，因此「什么时候保存」「怎么带走」这两件事需要你心里有数。这篇文档说明保存机制、多白板管理、历史版本与全部导出格式。

## 自动保存

- 每次改动后，顶栏保存状态依次显示 `保存中…`、`已保存到本机`。
- 不需要手动点保存，也不需要联网。
- 出现 `保存失败` 时，页面会提示「本机保存失败，请导出 JSON 备份白板内容」。常见原因是浏览器存储空间不足、处于受限模式，或浏览器禁止站点保存数据。请立即导出 JSON，再检查浏览器设置。

详细的数据边界说明见 [快速开始](快速开始.md)。

## 多白板管理

| 操作 | 位置 | 说明 |
| --- | --- | --- |
| 新建 | 顶栏「文件 → 新建白板」或左侧白板标题旁的加号 | 新白板名为「未命名白板」 |
| 切换 | 左侧白板列表单击 | 每个白板记住自己的视图与缩放 |
| 重命名 | 顶栏名称框，或左侧列表双击 | 名称不能为空 |
| 创建副本 | 左侧「…」菜单或顶栏「文件 → 创建副本」 | 副本名称为「原名 副本」 |
| 清空内容 | 顶栏「文件 → 清空内容」 | 删除当前白板全部元素，可撤销 |
| 删除白板 | 左侧「…」菜单或顶栏「文件 → 删除白板」 | 不可撤销；删掉最后一个白板会自动补一张空白白板 |

## 历史版本

左侧栏底部「历史版本」打开弹层。

- **手动保存**：输入版本名称（可留空，留空时叫「手动版本」），点「保存当前版本」。
- **自动备份**：编辑过程中系统会每两分钟检查一次，条件满足时自动存一版，名称是「自动备份」，最多保留最近 15 条自动备份。
- **列表信息**：每条显示名称、「手动 / 自动」、时间与元素数量，按时间倒序。
- **恢复**：点「恢复」把白板内容与视图还原到该版本，恢复操作本身可以撤销。
- **删除**：点「删除」移除该版本记录，不会影响当前白板内容。

版本只记录当前白板的元素与视图，不包含评论与演示路线。

## 导出

顶栏「导出」打开弹层，先选三个参数，再选格式。

### 三个参数

| 参数 | 选项 | 说明 |
| --- | --- | --- |
| 范围 | 全部内容 / 选中元素 / 当前视图 | 选中元素要求先有选区，否则按钮不可用；当前视图按你此刻看到的画面裁切 |
| 倍数 | 1x / 2x / 4x | 对 PNG 生效，决定像素密度；SVG 始终按矢量导出 |
| 背景 | 白色 / 透明 | 透明背景适合叠到别的文档或幻灯片上 |

### 六种输出

| 格式 | 适合场景 | 说明 |
| --- | --- | --- |
| PNG 图片 | 插入文档、幻灯片、聊天 | 由当前画面光栅化，所见即所得 |
| SVG 矢量图 | 需要继续在矢量软件里编辑 | 保留元素结构，不含选择框等界面元素 |
| JSON 源文件 | 备份、迁移、发给别人继续编辑 | 包含白板名称与全部元素 |
| PDF / 打印 | 打印或存档 | 打开打印窗口后选择「另存为 PDF」 |
| Markdown 大纲 | 转成文本继续写 | 把结构导出为标题与列表 |
| 导入 Markdown | 从文档生成白板 | 读取 .md 文件后在当前白板追加元素 |

导出过程较长时，弹层会显示「正在生成 2x PNG，请稍候…」这类进度文案，完成后弹出提示。白板为空时导出图片会提示「白板还没有内容可以导出」；范围选了「选中元素」却没选元素时提示「请先选择要导出的元素」。

### 导入 JSON

顶栏「文件 → 导入 JSON」选择文件。导入会**替换当前白板的全部内容**，导入前会弹确认框并显示元素数量；如果文件里带白板名称，当前白板会被改名。文件格式不对或没有可用元素时，会提示「导入失败」并说明原因。

### Markdown 的映射规则

导出时：

- 思维导图按层级生成 `#` 标题。
- 便签与文本生成列表项。
- 卡片生成带完成状态的任务项，例如 `- [x] 写完方案 (已完成)`。

导入时：

- `#` 标题生成文本元素。
- `- [x] 任务` 生成卡片。
- 普通列表与段落生成便签。

导入 Markdown 是追加，不会清空当前白板；导入后这些元素会被选中并自动适配视野。

## 画布统计

左侧栏底部「画布统计」显示：元素总数、评论数、便签投票总票数、已锁定数量、已隐藏数量、容器数量，以及按类型的元素分布（便签、文本、图形、连接线、容器、导图、表格、卡片、画笔、图片）。

统计只针对当前白板，可用来检查是否有忘记解锁或隐藏的内容。
