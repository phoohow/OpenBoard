# OpenBoard · 本地优先的无限画布白板

OpenBoard 是一款受 BoardMix 启发、以浏览器为载体的**本地优先**可视化白板工具。无需注册、打开即用，内容自动保存在当前浏览器。你可以在无限画布上组合文本、便签、图形、连接线、图片、手绘笔迹、思维导图、表格、卡片与容器，用于头脑风暴、流程梳理、项目规划和灵感整理。

> 本项目仅借鉴通用产品交互，不使用 BoardMix 的品牌、专有素材或源码。

## 功能速览

- **无限画布**：点阵/网格/横线/空白四种背景，滚轮缩放（10%–300%）、抓手平移、小地图、适配内容与 100%、智能参考线与网格吸附。
- **创作工具**：13 个工具——选择、抓手、便签、文本、图形（7 组共 52 种）、连接线（直线/正交/曲线）、画笔（钢笔/记号笔/荧光笔）、橡皮、图片、容器、思维导图（4 布局 6 主题）、表格、卡片，另有评论批注与便签投票。
- **编辑与排版**：选择/多选/框选、移动缩放旋转、复制粘贴与再制、群组、图层（置顶置底、锁定、隐藏、图层面板）、样式、六向对齐与等距分布、查找与全局替换。
- **资源与素材**：图形库、25 套模板（5 个分类 + 收藏）、素材库（贴纸/图标/印章），以及持久化在 localStorage 的**收藏**。
- **数据与导出**：自动保存与多白板、历史版本（手动 + 自动快照，自动版本保留 15 条）、JSON 导入导出、PNG（1x/2x/4x、透明背景、三种范围）/ SVG / PDF 打印、Markdown 双向、画布统计。
- **演示与分享**：元素 / 幻灯片 / 路线三种演示模式、激光笔、计时器、互动表情、路线站点编排，以及分享弹层导出 JSON 副本。

## 快速开始

```bash
# 环境要求：Node.js 18+ 与 npm
npm install        # 安装依赖
npm run dev        # 启动开发服务器（默认 http://localhost:5173）
npm test           # 领域单测（Vitest，8 个文件 55 条用例）
npm run check      # 分层守卫（依赖方向 + 旧符号残留）
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 本地预览构建产物
```

## 技术栈

**React 19** + TypeScript + Vite；以 SVG 渲染画布与所有元素，CSS 实现工作台界面；浏览器 `localStorage` 持久化。采用元素 ID 关联连接线，以视图变换（`View{x,y,zoom}`）统一处理无限坐标、缩放与平移。

## 源码分层

源码按「纯模型 → 纯几何 → 纯业务 → 适配器 → 应用 → 装配」组织，依赖单向向下，跨目录引用统一走 `@/` 别名：

- `src/model/` — 类型、常量、工厂与预设（零内部依赖）
- `src/geometry/` — 纯几何：包围盒、文本布局、形状轮廓、连接线、命中与吸附
- `src/domain/` — 纯业务：文档模型 + 命令（唯一写入口的纯函数）+ 命令历史 + 派生选择器 + 导图算法
- `src/features/` — 适配器：localStorage 持久化、导出、Markdown、模板与素材库
- `src/app/` — 应用层：单例 store（`dispatch` 唯一写入口）+ 分组 actions + 副作用 + 指针/键盘状态机 + `useEditor` 门面
- `src/canvas/` — 画布呈现：渲染器与交互覆盖层，仅接窄 props
- `src/ui/` — 工作台组件：layout / panels / dialogs / common

`src/App.tsx` 只做装配（≤100 行）；`ui` / `canvas` 不依赖 `@/app`，`domain` / `geometry` 不依赖 React——前者由 `npm run check` 静态守卫，后者由 `npm test` 的纯函数单测验证。样式按职责拆分在 `src/styles/`，由 `index.css` 按序汇总。分层细节、命令表、数据流与扩展指引见 [开发者文档 · 架构总览](docs/dev/架构总览.md)。
